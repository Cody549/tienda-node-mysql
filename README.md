# 🛒 Sistema de Inventario - Tienda

Este proyecto consiste en una API REST desarrollada con Node.js y MySQL para la gestión de productos de una tienda de electrónicos.

## 🚀 Funcionalidades

- Crear productos
- Listar productos
- Actualizar productos
- Eliminar productos

## 🛠 Tecnologías utilizadas

- Node.js
- Express
- MySQL
- XAMPP
- Thunder Client
- Visual Studio Code

## ⚙️ Instalación y ejecución

1. Clonar el repositorio
2. Instalar dependencias:
   npm install
3. Iniciar MySQL desde XAMPP
4. Ejecutar el servidor:
   node index.js
5. Acceder desde:
   http://localhost:3000

## 🧪 Pruebas

Se utilizó Thunder Client para probar los endpoints del CRUD (POST, GET, PUT, DELETE).
